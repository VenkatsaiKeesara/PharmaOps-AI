# Objective

The Suppliers_Master dataset stores supplier information required for procurement, inventory management, purchase analysis, and supplier performance analytics.

The dataset acts as the master reference table for all procurement-related transactions.

---

# Source Dataset

Reference Dataset

data/reference/Supplier_Names.csv

The reference dataset contains:

- Supplier Name
- Supplier Type
- City
- State
- Company Domain

The generation script enriches the reference data by creating business attributes.
